# Security Policy

## Supported Versions

Security fixes are prioritized for active **Flagship** and **Tools** projects under their latest stable release tags.

| Category | Repositories | Supported |
|---|---|---|
| Flagship | INKREST, Browsory, ProxyDuck, Loomark | ✅ Latest Release |
| Tools | RunTelos, Metaxy, StackHome, Orthos, LANDrop, etc. | ✅ Latest Release |
| Labs | Experimental repositories | ⚠️ Best effort |
| Archived | Historical repositories | ❌ Deprecated |

---

## Reporting a Vulnerability

If you discover a security vulnerability or potential data leak in any repository under `@rowanjove`:

1. **Do not create a public issue.**
2. Use GitHub's private vulnerability reporting feature on the respective repository (`Security` → `Report a vulnerability`), or contact via GitHub profile private channels.
3. Include detailed reproduction steps, target platform (Windows version, runtime), and potential impact.

We take security and local user data isolation seriously and will respond promptly to investigate and remediate reported issues.
