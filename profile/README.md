# RowanJove

> **Local-first software for personal computing.**  
> 为个人计算环境构建本地优先的软件。

This repository (`RowanJove/.github`) hosts account-wide GitHub community templates, security policies, and reusable CI/CD workflows for repositories under `@rowanjove`.

---

## Ecosystem Structure

All repositories adhere to a four-tier portfolio architecture:

- **Flagship**: Core representative products ([INKREST](https://github.com/rowanjove/INKREST), [Browsory](https://github.com/rowanjove/Browsory), [ProxyDuck](https://github.com/rowanjove/ProxyDuck), [Loomark](https://github.com/rowanjove/Loomark))
- **Tools**: Focused single-purpose daily utilities ([RunTelos](https://github.com/rowanjove/RunTelos), [Metaxy](https://github.com/rowanjove/Metaxy), [StackHome](https://github.com/rowanjove/StackHome), [Orthos](https://github.com/rowanjove/Orthos), [LANDrop](https://github.com/rowanjove/LANDrop), [MarkClip](https://github.com/rowanjove/MarkClip), [Postcase-X](https://github.com/rowanjove/Postcase-X), [CF-Nexarch](https://github.com/rowanjove/CF-Nexarch), [WebVault](https://github.com/rowanjove/WebVault))
- **Labs**: Experimental prototypes and concept explorations
- **Archived**: Read-only historical repositories preserved for reference
